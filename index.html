Usually Documents\My Games\Tabletop Simulator\Saves\Saved Objects. In the game, find it under Objects > Saved Objects. To share with friends, use Modding > Cloud Manager > Upload All Loaded Files after you spawn it (steps are in the README it makes).

How to write game text

Type plain text. The studio formats it for you:

POWER: Draw a card.Bold power label
REACTION: … Setup: …Bold labels
Start Phase: … or [End Phase] on its own lineRed phase label
> text or - textArrow bullet
(H)H (number of heroes) icon
[flip] (F)Flip icon
{sun} {hand} {ankh} {myicon}A small icon in the line: ready-made ones, or your own pictures from Text icons
SUN: … HAND: … ANKH: … at the start of a lineThe Ennead god symbol and its bold word, like the printed cards
**words** / _words_Bold / italic
“Extra bolded terms” fieldBolds those words everywhere

Text shrinks automatically to fit its box; the Text size slider sets the starting size.

First Appearance cards show the hero's debut comic in a graded case. Build the cover right here (masthead, issue, price, blurb, speech bubble, era, age and wear) or upload a finished cover. Use “First Appearance (front + back)” to make both sides at once; the back is the “Notable Defeat” cover with the incapacitated options.

Events: “Event (front + back)” makes the event card and its Collection back (featured cover, issue list, two rewards). “Critical Event (front) + Villain character” makes the critical event front and the replacement villain card on its back. In Tabletop Simulator the landscape back is turned to fit the card.

Copies: set “Copies in the deck” (under Print and decks) on any deck card. The list shows ×2, ×3, and the top of the list counts each deck (a hero deck is 40 cards). Print, PDF and Tabletop Simulator all use it.

Adding art: drop a picture on the card, paste one (or an image link) with Ctrl+V, or drag a picture straight from another browser tab. Add art to many cards… (or dropping several pictures on the card list) puts each picture on the card whose title matches its file name; end a file name with -fg for the cut-out spot or -bg for the background. Remove background… turns a picture on a plain background into a cut-out. From project… reuses a picture another card already has; project files store it once.

Two heroes in one project? Give each deck card and deck back a Deck name (in Print and decks). Cards with the same name count together, export to Tabletop Simulator as their own deck with the back of the same name, and fill a divider that has that name.

Dividers are the square deck dividers from the Definitive Edition box: the front shows the deck name and art, the back lists the cards. On the back press Fill from this project to list your deck cards with their copies.

Enhanced Edition makes cards in the original look (yellow, blue and green title bars, all-caps lettering, speech-balloon quotes), including villain instructions cards and the oversized team villains. OblivAeon has the booklet page, Scions, Missions (objective side with its reward on the back), Shields, Battle Zones, Inevitable Destruction, the Scion Reserve, reminder cards, and the OblivAeon and Aeon Men decks with their backs.

Art versions: press + Version under a picture to keep it, then add a different picture. Click a version to switch to it.

Move parts: tick it above the card to drag the title, text box, logo and the rest; scroll to resize; double-click a part to put it back; Reset layout puts them all back.

Art is framed for you when you add it (it finds the subject and fits it to the spot). Use Crop… for exact control, or drag and scroll on the card.

Tabletop Simulator makes deck sheets and a Saved Object. Put character fronts right before their backs in the card list (front, then back) so they pair up. Deck cards use the project's deck back of the same kind.

Everything saves automatically in this browser. Use Save project file to back up or share a project (art included), and Import to load it again. Import also reads Unity's Workshop JSON and CSV/TSV spreadsheets.
