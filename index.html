How to write game text

Type plain text. The studio formats it for you:

POWER: Draw a card.Bold power label
REACTION: … Setup: …Bold labels
Start Phase: … or [End Phase] on its own lineRed phase label
> text or - textArrow bullet
(H)H (number of heroes) icon
[flip] (F)Flip icon
**words** / _words_Bold / italic
“Extra bolded terms” fieldBolds those words everywhere

Text shrinks automatically to fit its box; the Text size slider sets the starting size.

First Appearance cards show the hero's debut comic in a graded case. Build the cover right here (masthead, issue, price, blurb, speech bubble, era, age and wear) or upload a finished cover. Use “First Appearance (front + back)” to make both sides at once; the back is the “Notable Defeat” cover with the incapacitated options.

Events: “Event (front + back)” makes the event card and its Collection back (featured cover, issue list, two rewards). “Critical Event (front) + Villain character” makes the critical event front and the replacement villain card on its back. In Tabletop Simulator the landscape back is turned to fit the card.

Art is framed for you when you add it (it finds the subject and fits it to the spot). Use Crop… for exact control, or drag and scroll on the card.

Tabletop Simulator makes deck sheets and a Saved Object. Put character fronts right before their backs in the card list (front, then back) so they pair up. Deck cards use the project's deck back of the same kind.

Everything saves automatically in this browser. Use Save project file to back up or share a project (art included), and Import to load it again. Import also reads Unity's Workshop JSON and CSV/TSV spreadsheets.
